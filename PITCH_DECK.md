## Slide 5: Technology Stack

**Title:** Modern & Scalable Architecture
**Content:**
-   **Frontend:** React, TypeScript, Ant Design (UI Library), Recharts (Charting)
-   **Backend:** Node.js, Express.js, TypeScript
-   **Database:** SQLite (with Prisma ORM)
-   **Authentication:** JWT (JSON Web Tokens)

**Script:**
"PolicyPulse is built on a robust and modern technology stack. Our frontend leverages React and TypeScript for a dynamic user experience, with Ant Design for a polished UI and Recharts for powerful data visualizations. The backend is powered by Node.js and Express.js, also in TypeScript, ensuring scalability and maintainability. We use SQLite with Prisma ORM for efficient data management and JWT for secure user authentication."
